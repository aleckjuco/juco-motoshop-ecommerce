# Kalye Moto — Ride Your Own Road (React + Vite)
npm install && npm run dev

Edit content:
- src/data/brand.js    brand name, tagline, colors, ticker text, hero slideshow slides
- src/data/products.js products (name, price, stock, category, specs, image / images)

Photos: put files in /public/images and set e.g. image: "/images/motorcycles/kalye-rider-125.png" (transparent PNG cutouts work best).
(extra gallery photos in images: [...]). For the hero, set slide.image to a wide photo.
Without images, the site draws colored illustrations. All data is in memory (useState); refresh resets it.
